## 4. Crawl & Indexing Rules

1. **Self-referential Canonical Tags**: Every route declares its unique URL (`https://milanmeter.com/...`).
2. **Preventing Parameter URL Creep**: Result screens render in the same URL without pushState URL query pollution that generates thousands of empty parameter URLs.
3. **Robots.txt Disallow**: Explicitly disallows `/*?*` to prevent web crawlers from indexing testing strings.
4. **XML Sitemap**: Canonical URLs submitted with accurate `<changefreq>` and `<priority>`.
